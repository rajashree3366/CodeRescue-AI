# ShopSphere Legacy

An intentionally undocumented legacy e-commerce application used as the demonstration codebase for CodeRescue AI.

## Situation

The original developer is no longer available.

The application still works, but the project contains:

* unclear architecture
* limited documentation
* tightly coupled modules
* missing tests
* outdated dependencies
* undocumented business logic
* unclear critical paths

## Purpose

This repository is intentionally designed as a realistic handoff problem.

CodeRescue AI analyzes this project and produces a Developer Rescue Map showing:

* project architecture
* important modules
* dependencies
* critical components
* documentation gaps
* test gaps
* potential maintenance risks

The rescue workflow can then be performed using IBM Bob.

## Application Flow

User
→ Authentication
→ Product Catalog
→ Cart
→ Checkout
→ Payment
→ Order

## Important Areas

* Authentication
* Product catalog
* Cart
* Checkout
* Payment
* Orders
* Database

## Known Handoff Problems

The purpose of this project is to allow CodeRescue AI to discover these problems rather than relying only on this README.

This project is intentionally incomplete and under-documented.
